## 知识库重建（law_index 缺失或损坏时）

本仓库分发完整的 `law_index/*.json`，不分发原始网页文件或构建脚本。JSON 中的 `source_file` 仅记录历史构建来源，不是运行依赖。索引缺失或损坏时，优先从本仓库重新下载这三个 JSON 文件。

确需重建时：向用户索取三部法律的官方文本文件（txt/docx/pdf/html），按现有 JSON 的字段结构重新构建；来源必须可核验（官方或政府网站转载），构建后必须做条数连续性校验（民法典1260/劳动合同法98/公司法266）与 sha256 记录，并按实际来源更新元数据。仓库未附自动重建工具，不能假设存在 `build_law_index.py`。**禁止**用模型记忆生成条文填充知识库。
