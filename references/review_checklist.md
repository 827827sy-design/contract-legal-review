# review_checklist.md — 合同核查清单

先按"通用事项"过一遍，再按合同类型加专项。每一项的结论都要落到具体原文证据上；没有证据支撑的疑点只能归"待核实事项"。

## 一、通用核查事项（所有合同）

### 1. 主体与签署
- 双方名称是否完整、前后一致（简称与全称是否对应）；自然人是否有身份信息。
- 签署形式：签名/盖章/按指印（民法典第490条）；是否约定生效条件。
- 代签情形：是否有授权委托；无权代理/表见代理风险（民法典第171、172条）→ 归"合同效力风险"或"待核实事项"。
- 公司对外担保/重大投资：是否提及股东会/董事会决议（公司法第15条）→ 未提及时列"待核实事项"（决议属外部事实，合同文本无法证明）。

### 2. 标的与履行内容
- 标的物/服务是否明确（名称、规格、数量、质量标准）；约定不明 → 民法典第510、511条补充规则，可提示"约定不明确"。
- 履行期限、地点、方式是否明确。

### 3. 价款与支付
- 金额大小写是否一致；币种；支付节点与条件；发票约定。
- 借款合同：利息约定是否明确（民法典第680条：未约定视为无息；自然人之间约定不明视为无息）；是否预先扣除利息（第670条）。

### 4. 交付与验收
- 交付方式、风险转移节点（民法典第604条：交付转移风险）；检验期限与异议（第620-621条）；验收标准与程序缺失 → 条款缺失。

### 5. 违约责任
- 违约金数额或计算方法（民法典第585条）；过高/过低均可请求调整——**中立提示双方**，不单为某方砍违约金。
- 定金规则（第586-588条：不超过主合同标的额20%；定金与违约金择一）。
- 赔偿范围（第584条可预见规则）；免责条款是否免除故意或重大过失责任（第506条：此类免责条款无效——表述为"该免责条款存在无效风险"，不认定合同整体无效）。

### 6. 格式条款（一方提供模板文本时必查）
- 民法典第496条：提供方的提示说明义务；第497条：无效情形（免除己方责任、加重对方责任、排除对方主要权利）；第498条：解释规则。
- 发现"甲方不承担任何责任""最终解释权归甲方"类条款 → 合同效力风险（条款层面），表述为"存在被认定无效的风险"。

### 7. 解除与终止
- 约定解除条件（第562条）与法定解除（第563条）；解除程序与通知（第565条）；解除后果（第566条）。
- 只赋予单方任意解除权且无对价安排 → 权利义务不对等提示（中立表述）。

### 8. 争议解决
- 诉讼/仲裁是否明确；仲裁条款是否有明确仲裁机构（约定"仲裁"但无机构 → 约定不明确；注意：仲裁法不在知识库内，仅按民法典合同编一般逻辑提示"争议解决条款可能无法执行"，不引用未入库法律）。
- 管辖法院约定是否存在（约定不明不影响起诉，提示完整性即可）。

### 9. 通知与送达
- 送达地址、方式、生效时间是否约定；缺失 → 条款缺失（完整性建议）。

### 10. 其他常见
- 保密条款、知识产权归属、不可抗力（第590条）、合同份数与附件效力、变更须书面（第543-544条：变更约定不明推定未变更）。

## 二、类型专项

### 劳动合同（laodonghetongfa 为主）
- **必备条款九项**（第17条）：单位信息、劳动者信息、合同期限、工作内容与地点、工作时间与休息休假、劳动报酬、社会保险、劳动保护/职业危害防护、其他。缺项 → 法律合规风险（法定必备）或条款缺失，逐项列。
- 试用期（第19条上限；第20条试用期工资≥80%且≥当地最低工资；第21条试用期解除限制）。
- 违约金：只有两种合法情形——服务期（第22条）与竞业限制（第23条）。**其他任何劳动者违约金条款 → 法律合规风险（第25条：不得约定由劳动者承担违约金）**。
- 竞业限制（第23、24条）：人员范围限高管/高级技术/保密义务人员；期限≤2年；经济补偿（解除后按月支付）。
- 解除与经济补偿（第36-50条）：单位单方解除条件、程序（工会，第43条）、经济补偿情形与标准（第46、47条）；违法解除赔偿金（第87条：二倍经济补偿）。
- 未签书面合同（第82条二倍工资）；扣押证件、要求担保、收取财物（第9条禁止）→ 出现即 high。
- 劳务派遣（第57-67条）：三性岗位、比例、同工同酬、行政许可。
- 免除单位法定责任、排除劳动者权利的条款（第26条）→ 条款无效风险表述。

### 买卖/采购合同（民法典第595-647条）
- 标的物描述、数量、质量标准（第615-616条）；包装（第619条）；检验期间与合理期限（第620-621条）；所有权保留（第641-643条）；风险负担（第604-611条）；分期付款解除门槛（第634条）。

### 租赁合同（第703-734条）
- 六个月以上应书面（第707条）；未书面且期限不明 → 不定期租赁。
- 租赁期限≤20年（第705条）；超20年部分无效 → 效力风险表述。
- 出租人维修义务（第712条）；转租需同意（第716条）；买卖不破租赁（第725条）；优先购买权（第726条）；押金返还未约定 → 约定不明。
- 不定期租赁任意解除权（第730条）。

### 借款/借贷合同（第667-680条）
- 书面形式（第668条，自然人之间可另约定）；利息不得预扣（第670条）；利率约定不明规则（第680条）；未约定还款期限的处理（第675条）。
- 注意：民间借贷利率司法保护上限属司法解释，**不在知识库**→ 如合同利率明显异常，只能提示"利率合法性需人工核实（超出本技能审查依据范围）"，不得引用 LPR 四倍等规则原文。

### 承揽/技术/建设工程合同（第770-808条、843-887条、788-808条）
- 承揽：任意解除权（第787条定作人）、留置（第783条）；技术合同：成果归属（第847、859-861条）、非法垄断技术条款无效（第850条）；建设工程：必须招标未招标/无资质/转包违法分包 → 效力风险（提示需结合行政法规人工核实，合同编第791条可直接引用）。

### 委托/中介/物业服务等（第919-966条）
- 委托合同任意解除权（第933条）与赔偿；中介报酬（第963-965条）；物业服务（第937-950条）。

### 股权/投资/公司治理相关协议（gongsifa 为主）
- 出资：认缴五年实缴（第47条，2024-07-01后新设公司）；非货币出资评估（第48条）；未按期缴纳的催缴失权（第51-52条）、加速到期（第54条）。
- 股权转让：优先购买权（第84条）；转让后出资责任（第88条）。
- 对赌/回购、股东权利限制：知识库仅覆盖公司法条文，效力问题多涉司法解释 → 待核实事项。
- 公司担保决议（第15条）；关联交易与董监高义务（第181-185条）；决议效力（第25-28条）。
- **时间效力**：合同签订/行为发生在2024-07-01前的，注意新公司法过渡期安排 → manual_checks 提示。

### 保证/担保条款（任何合同中出现）
- 民法典第681-702条：保证方式约定不明推定一般保证（第686条，注意这是民法典对担保法的改变）；保证期间（第692条：约定不明为主债务届满后6个月）；独立担保条款效力 → 待核实（涉司法解释）。

## 三、核查纪律

1. 每个疑点先问：三部法律里有直接依据吗？有 → 引用并归类合规/效力；没有但影响完整性 → 条款缺失/约定不明；需要外部事实 → 待核实事项。
2. 中性表述自查：conclusion/explanation 中不得出现"对甲方极为不利，应争取"式单方立场语言。
3. 数量控制：合并同质问题（同一缺陷重复出现在多个条款 → 一条风险多个证据），但不同性质问题不得合并。
